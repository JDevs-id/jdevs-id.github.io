01 / تخصصات التعليم العالي

سياق أكاديمي. تقنيات مؤسسية.

تشمل خبرتي الجوانب الأكاديمية والإدارية والتشغيلية للجامعة. ويأتي تطوير التطبيقات ضمن خبرة أوسع في الأنظمة المؤسسية والبيانات وتقنيات التعليم.

01

أنظمة التعليم العالي

تحليل المتطلبات والمسارات الرقمية للإدارة الأكاديمية والبحوث وخدمات أعضاء هيئة التدريس وشؤون الطلبة والمكتبات والتقارير المؤسسية.

02

حوكمة البيانات الأكاديمية

سلامة السجلات الأكاديمية والتحقق والمزامنة والتقارير التنظيمية للتعليم العالي، مع التركيز على جودة البيانات والمساءلة المؤسسية.

03

ضمان الجودة والتحليلات

مؤشرات الخطط الاستراتيجية والتقييم القائم على الصيغ وتحليلات مؤشرات الأداء والتقارير المنظمة وملخصات الأداء ومخططات الرادار عبر SIAMI.

04

تقنيات التعلم وخدمات الذكاء الاصطناعي

منصات التعلم وتتبع التقدم؛ إدارة Google Workspace for Education والوصول والأمن؛ تهيئة Gemini for Education وNotebookLM ودعم اعتمادهما.

05

البنية التحتية المؤسسية

استضافة تطبيقات وقواعد بيانات Linux والمراقبة والنسخ الاحتياطي عبر Synology؛ شبكات MikroTik/UniFi وأجهزة المستخدمين والفعاليات الهجينة والبث.

06

هندسة التطبيقات وتكاملها

PHP/Laravel وCodeIgniter وReact/Inertia.js وREST APIs ومسارات قواعد البيانات؛ خبرة Flutter/Firebase وتركيز حالي على React Native.

الأساس الهندسي

Laravel / PHP · CodeIgniter · React / Inertia.js · TypeScript · MySQL / PostgreSQL · REST APIs · Linux · Git / GitHub
